# Yohan Creator Website

A responsive personal creator / link-hub website for Yohan Ary / Himanshu.

## Files
- `index.html` — main page
- `styles.css` — full design
- `script.js` — animations + mobile menu
- `downloads/Planko-Fly.apk` — direct Planko Fly Android download

## Run locally
Open `index.html` directly in your browser.

Or, from the folder:

```bash
python3 -m http.server 8000
```

Then open:
`http://localhost:8000`

## What to replace next
Search for these placeholders in `index.html`:
- `@yourhandle`
- `@your_instagram`
- `discord.gg/yourlink`
- `t.me/yourchannel`
- `@yourchannel`
- `@yourgithub`
- `yourmail@example.com`
- the remaining placeholder featured-post links
